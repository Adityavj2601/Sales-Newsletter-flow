# Sales Newsletter Flow

A weekly, AI-curated sales newsletter delivered as one shareable link (with a
WhatsApp/LinkedIn preview card) plus a matching email version. Prospects can show
interest with one tap.

📘 **Full product blueprint:** [docs/BLUEPRINT.md](docs/BLUEPRINT.md)

- End-to-end weekly flow: ingest → AI draft → quality gate → review → send → capture intent
- Content pillars: industry pulse · feature showcase · delivered work · concepts (honest wording rules)
- Dashboard ("Studio") screens, AI provider/key setup, scheduled jobs
- What to do / what not to do, compliance, tech stack, phased build plan
